Introduction to lidR for Forest Inventory

Airborne LiDAR processing and forest inventory applications

Overview

This section introduces the use of the lidR R package for processing airborne laser scanning (ALS) data and deriving information relevant to forest inventory. The tutorials are organized as a sequence of independent topics, from reading point-cloud data to area-based and individual-tree approaches.

Tutorial materials

The following pages will be developed as the tutorial progresses. Each currently serves as a placeholder for examples, code, and exercises.

Tutorial Topic
1-LAS Reading, exploring, and filtering LAS/LAZ point clouds
2-DTM Digital terrain models and height normalization
3-CHM Canopy height models
4-METRICS Point-cloud and canopy metrics
5-LASCATALOG Processing collections of LiDAR files
6-ROI Working with regions of interest
7-ABA Area-based approaches to forest inventory
8-ITS Individual-tree detection and segmentation

Requirements

R and RStudio

A recent version of R is required. RStudio is recommended for working through the examples.

R packages

Install lidR to get started:

install.packages("lidR")

Additional packages and datasets will be listed within the individual tutorials as needed.

About lidR

lidR is an open-source R package for analyzing airborne LiDAR point clouds, creating raster products, and extracting forest structure information. The pages in this section focus on its applications to forest inventory. The package was developed at Université Laval in Québec, Canada, and is maintained by Jean-Romain Roussel. The current release is available on CRAN, and its source code is hosted on GitHub.

r-lidar

The r-lidar organization supports the continued sustainability of the software and offers training, consulting, and development services. Jean-Romain Roussell is commited to maintaining the lidR packages as fully open source.
